# SBA Circuit Forge

SBA Circuit Forge is a tool designed for E&I Technicians & HND Engineering Students.
It consists of three isolated engines:
1. **SBA Circuit Forge (Frontend Workspace)**: C++ / Qt frontend.
2. **SBA Pulse (Local SPICE Engine)**: C++ wrapper for ngspice.
3. **SBA Aegis (AI Mentor Backend)**: Python FastAPI backend for AI diagnostics.

Please see `Agent.md` for architecture and agent directives.
